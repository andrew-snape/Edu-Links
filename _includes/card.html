{%- comment -%} Renders one link card. Expects `link` with name / url / description / (optional) logo. If no `logo` is given the site's favicon is fetched from Google's favicon service. If that image fails to load - a 404, or a school network that blocks the service - the inline onerror handler drops it and flags the wrapper, which reveals a letter tile instead of a broken-image icon. These are ~1KB images, and lazy-loading them would mean onerror never fires for cards below the fold, leaving them blank instead of falling back. So they load eagerly on purpose. {%- endcomment -%} {%- assign domain = include.link.url | remove_first: "https://" | remove_first: "http://" | split: "/" | first -%} {%- if include.link.logo -%} {%- assign logo_src = include.link.logo -%} {%- else -%} {%- assign logo_src = "https://www.google.com/s2/favicons?sz=64&domain=" | append: domain -%} {%- endif -%} {%- assign letter = include.link.name | strip | slice: 0 | upcase -%} {%- comment -%} Sites with no discoverable favicon fall back to a letter tile. With every tile the same colour, two failed favicons that happen to share an initial letter render as visually identical cards - the "these look like copies" problem. Spreading tiles across a small palette, keyed off a cheap hash of the name/domain (so it's stable across builds without needing real randomness), keeps same-letter fallbacks visually distinct. {%- endcomment -%} {%- assign tile_wc = include.link.name | split: " " | size | times: 17 -%} {%- assign tile_dsize = domain | size | times: 5 -%} {%- assign tile_nsize = include.link.name | size -%} {%- assign tile = tile_wc | plus: tile_dsize | plus: tile_nsize | modulo: 8 -%} {{ include.link.name }} {% if include.link.description %}{{ include.link.description }}{% endif %} {{ domain }}
